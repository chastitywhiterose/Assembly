About AAA BIOS

This book continues where the 16-bit DOS book left off. As it turns out, it is possible to develop 16-bit applications without requiring DOS or even having an operating system at all. This is because of the BIOS (Basic Input/Output System), which allows for sending text output to the screen or reading characters from the keyboard.

If you enjoyed the DOS book and find yourself craving more 16-bit Assembly language programs that can be developed even faster, you might be interested in this book. You will learn to use QEMU as a tool for faster minimal operating system development using code tested for the FASM and NASM assemblers.
